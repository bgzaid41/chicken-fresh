# Chicken Fresh Delivery App

A working Expo/React Native MVP for a chicken shop delivery business.

## Features
- Customer home/product catalog
- Search and categories
- Cart and checkout with address
- Cash on Delivery
- Order history and status
- Profile
- AsyncStorage for local persistence
- Basic admin mode
- Admin order status controls
- Shop open/closed toggle
- Responsive mobile UI

## Run
1. Install Node.js
2. Run `npm install`
3. Run `npx expo start`
4. Scan the QR code with Expo Go or run `npm run android`
